Offline GTA-VI-style cover art maker built for the make.fun bounty gta6-cover-art-01: load any
photo from disk, crop/zoom/pan it into 2-4 comic panels, edit the caption, pick a neon palette
and export a PNG at 1080x1080, 1080x1350 or 1920x1080. Static files, runs offline in desktop
Chrome, photos never leave the machine. All art, lettering and fonts are original — no
Rockstar Games logo, artwork or fonts.

## Run it

```sh
npx serve .    # or open index.html directly in desktop Chrome
```
